# 🕵️ Ferramentas de OSINT para a Dark Web

Este repositório serve como um guia consolidado de ferramentas de Open Source Intelligence (OSINT) e recursos focados na Dark Web, essenciais para profissionais de segurança cibernética, pesquisadores e entusiastas.

> **⚠️ Aviso Legal:** O conteúdo e as ferramentas listadas aqui são estritamente para fins educacionais, de pesquisa e de segurança ética. O uso indevido para atividades ilegais é de inteira responsabilidade do usuário.

---

## 🛡️ 1. Acesso Seguro e Navegação

Ferramentas essenciais para garantir um acesso anônimo e seguro à rede Tor e aos sites `.onion`.

* **TOR Browser:** O principal software para acessar a Dark Web, garantindo o anonimato através de múltiplas camadas de criptografia e retransmissão de tráfego.
* **TOR2Web:** Serviços que permitem acessar sites `.onion` através de um navegador comum, sem a necessidade do Tor Browser (Nota: Oferece menos anonimato).
* **Onion.live:** Recurso para verificar e encontrar links `.onion` que estão atualmente online e funcionando.

---

## 🔎 2. Motores de Busca (Search Engines)

Estes motores são especializados em indexar conteúdo oculto na Dark Web, que não é acessível por motores de busca tradicionais (Google, Bing, etc.).

| Motor de Busca | Descrição |
| :--- | :--- |
| **Ahmia** | Interface limpa e fácil de usar para pesquisas na rede Tor. |
| **HayStack** | Motor de busca avançado, focado na profundidade da indexação de sites `.onion`. |
| **Tor66** | Um motor de busca clássico da dark web. |
| **Torch** | Historicamente, um dos motores de busca mais antigos e conhecidos da rede Tor. |

---

## 📧 3. Verificação de Vazamentos e Invasões

Ferramentas críticas para determinar se dados pessoais, contas de e-mail ou outras credenciais foram expostas em incidentes de vazamento de dados.

* **HaveIBeenPwned:** Verifica se um endereço de e-mail ou senha foi comprometido em algum vazamento de dados conhecido.
* **DeHashed:** Permite pesquisar dados específicos vazados.
* **Library of Leaks:** Um vasto banco de dados de credenciais e informações vazadas.
* **Aleph:** Ferramenta para pesquisa aprofundada em dados expostos.

---

## 🤖 4. OSINT no Telegram

O Telegram é uma plataforma chave na Dark Web para comunicação, grupos e venda/troca de informações vazadas.

| Ferramenta / Bot | Finalidade |
| :--- | :--- |
| **Telemetry** | Pesquisa por grupos, canais e chats específicos do Telegram. |
| **LeakOSINT** | Bot do Telegram dedicado à investigação de vazamentos de dados. |
| **UniversalSearchBot** | Bot do Telegram para pesquisar vazamentos de dados relacionados a endereços `.onion`. |

---

## 🔗 5. Diretórios de Links Onion

Listas e diretórios que ajudam a navegar e descobrir endereços `.onion` ativos.

* **Tor.link:** Um diretório de links onion cuidadosamente selecionados.
* **DarkwebDaily.live:** Diretório onion atualizado regularmente.
* **The Hidden Wiki:** Uma lista clássica de sites onion, geralmente mantida pela comunidade.
